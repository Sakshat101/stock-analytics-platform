# Stock Analytics Platform

A full-stack stock analytics platform built using React, Node.js, PostgreSQL, Socket.IO, and FastAPI.

## Features

### Market Dashboard

* Live stock market overview
* Top gainers and losers
* Market breadth analysis
* Interactive stock charts

### Portfolio Management

* Buy and sell stock simulation
* Holdings tracking
* Portfolio valuation
* Unrealized profit/loss calculation

### Watchlist

* Add and manage favorite stocks
* Real-time price monitoring
* Performance tracking

### Alerts System

* Create stock price alerts
* Above/below target conditions
* Alert management dashboard

### News Sentiment Analysis

* Sentiment scoring
* Bullish/Bearish indicators
* Stock-specific news insights

### Portfolio Analytics

* Risk analysis
* Portfolio health metrics
* Sector allocation breakdown

### AI Forecasting

* FastAPI-powered prediction service
* 7-day stock forecast
* Future price estimation
